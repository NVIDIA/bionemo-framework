# ARC independent regression fixtures

These are external oracles, not outputs regenerated by the implementation under test.

## Pinned upstream functions

`arc_pipeline_upstream.py` contains function bodies from ARC commit
`53f195997257c56c00e5ef8d33a54f5baad143a6`, with **trailing whitespace only removed**
and reduced imports so CPU CI does not need an installed ARC checkout. Code tokens,
comments and all other function formatting are preserved. Each original line span,
raw-source SHA-256 and whitespace-normalized SHA-256 is recorded in the fixture;
the integrity test checks the normalized bodies. The complete original source SHA-256 is
`ab1a5d388dcd2085ad79909ea15f3666740d76486f8e4b43d25fdf6fb5553091`.
Do not format or update these bodies merely to make a changed implementation pass.

## Published AAI and archived alignments

`arc_aai_publication.json` binds five exact genome sequences and published AAI/hit
counts to [King et al., Science, Data S1](https://doi.org/10.1126/science.aec2657).
It records the workbook SHA-256, sheet, and one-based Excel row, plus the archived
2026-09-10 individual-PHROGs-member search, tool versions and artifact hashes.
The retained hit-bearing ORFs have coordinates and peptides that translate from
the workbook sequences. For each ORF, the fixture retains the first minimum-E-value
hit and first maximum-identity hit in original file order. This preserves the
correct result while detecting a maximum-identity substitution.

- Evo-Φ4 and Sheet 1 row 18 independently reproduce published AAI on opposite
  sides of 95%, with an absolute tolerance of **1e-8 percentage points**, solely
  for decimal serialization/arithmetic. Both have 11 admitted ORFs.
- Sheet 1 rows 30, 67 and 161 preserve **all three known 95% decision mismatches**
  in the historical 302-design search. They match archived raw-hit aggregation,
  not the paper. Their differences are not hidden by a permissive tolerance.
- Across that archived 302-design probe, 299/302 novelty decisions and 291/302 hit
  counts agreed with Data S1; mean absolute AAI error was 0.147738 percentage
  points, maximum 5.338095. This is not full publication reproduction.

Tests compare the new aggregation with both published values and independent
upstream hit selection/GFF arithmetic. The definition is the unweighted mean of
one lowest-E-value natural-member hit per ORF, retaining the first equal-E-value
hit. It is **not** profile-consensus identity, best identity, one hit per family,
or a coverage-weighted mean.

These tests validate aggregation and sequence/peptide binding on saved search
evidence. They do **not** rerun ORF discovery or MMseqs, prove database-byte
identity with the authors, or prove that physical circular-ORF cleanup matches
the paper's original inventory. Current physical-ORF AAI and structured K+X
acceptance are explicit scientific extensions and have separate contract tests;
they must not be described as unchanged upstream ARC endpoints.

## Physical circular-ORF cleanup

`test_arc_circular_parity.py` binds the cleanup utility to actual translated DNA
from all five workbook sequences. An independent forward first-ATG-to-next-stop
enumerator with the archived 90-1800-nt convention recovers all 50 archived
coordinate/peptide records. Middle-copy ORFs from three full genome copies form
the physical-locus oracle. Inputs instead use the pinned upstream extension at
four cuts per genome (20 representations), exercising actual prefix and extension
removal while checking DNA, peptide, frame and physical start/stop positions.
The real Evo-Φ4 39-aa prefix tail disappears and the spanning 522-aa A remains.

A distinct-locus stress control uses three correctly translated intervals from
real Sheet 1 row 30 DNA; two complete six-nt calls share a peptide suffix with a
spanning ORF but have different physical stops and must remain. Those short calls
deliberately fall below both maintained and archived caller minima: they test the
cleanup utility, not a claim that ORFipy would emit them. A mutant that omits
prefix-tail removal fails the physical-inventory oracle.

These checks do not rerun ORFipy or searches, settle biological initiation/A*
products, validate reverse-strand discovery, or demonstrate arbitrary-genome
rotation invariance or unchanged published AAI. The four tested cuts and declared
forward enumeration convention define their scope.
